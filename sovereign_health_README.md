# Sovereign Health — Landing Page

A conceptual overview page explaining Sovereign Health and its six value components in plain language.

## Files
- `index.html` — the complete page (self-contained; all illustrations are inline SVG, no external image dependencies)
- `preview_desktop.png` / `preview_mobile.png` — reference screenshots

## Deploy (GitHub Pages)
1. Create a repository (e.g. `sovereign-health-landing`).
2. Upload `index.html` to the repo root.
3. Settings → Pages → Source: `main` branch, `/root`.
4. Your page goes live at `https://<username>.github.io/<repo>/`.

## Notes
- The page is fully self-contained — no build step, no external assets to upload. Just `index.html`.
- The Sovereign Health Network and Sovereign Health Fund are presented as **future-state** concepts.
- The footer disclaimer contains a red `[Counsel to confirm final language.]` placeholder — have counsel review before publishing, and confirm nothing reads as a securities offering.
